# PresBuilder

Анимированные ролики из текста озвучки. Вставляешь текст — он сам режется на слайды и реплики
по времени, а сцены рисует ИИ-агент (Claude Code или Codex). Ты правишь текст, тайминги и
положение объектов в редакторе и получаешь MP4 1080p/4K.

Четыре стиля оформления: **Terevo** (тёмный графит, узкая капитель), **Полночь** (тёмно-синяя
стена, охра и ржавчина), **Бумага** (светлая бумага, книжная антиква), **Линии** (белая дымка,
цветные полосы и тонкие линии). Стиль выбирается при создании темы и меняется в любой момент.

*Animated explainer videos from a voice-over script: an editor plus scenes written by an AI agent.*

## Запуск

Нужны [Node.js](https://nodejs.org) 22.18+ и Chrome или Edge.

```bash
git clone https://github.com/xaidan777/PressBuilder
cd PressBuilder
npm install
npm run dev
```

На Windows — двойной клик по `PresBuilder.bat`. Редактор откроется на http://localhost:5180.

## Как сделать ролик

1. **Новая тема** в редакторе: стиль, заголовок и текст озвучки.
2. Открой папку проекта в **Claude Code** или **Codex** и скажи: `делай тему <id>`.
   Агент нарисует сцены по скиллу `presbuilder`, редактор подхватит их сразу.
3. Поправь текст, тайминги и объекты. Есть запись голоса — добавь её кнопкой **«Добавить звук»**
   на таймлайне, агент подгонит реплики под паузы.
4. Нажми **«Вывод»** → `out/<id>.mp4` (вместе с озвучкой).

Пример с готовыми сценами: `gameready-3d` — «Game-Ready 3D модели с помощью AI», 20 слайдов.
Подробно — в [руководстве](docs/guide.md).

## Проверка готового MP4

После **«Вывод»** можно проверить технические параметры файла: кодек H.264,
разрешение и соотношение 16:9, FPS, длительность и наличие звука (если он задан в теме).

Нужен установленный `ffprobe` в `PATH` (либо переменная окружения `FFPROBE` с путём к нему).

```bash
npm run qa:mp4 -- gameready-3d             # out/gameready-3d.mp4 + настройки deck.json
npm run qa:mp4 -- out/gameready-3d.mp4     # только общие технические проверки
npm run qa:mp4 -- gameready-3d --json     # JSON для скриптов
npm run test:qa                           # регрессионные тесты
```

Команда возвращает код **0** при техническом `PASS`, **1** при обнаруженных
проблемах (включая отсутствие или повреждение MP4) и **2** при неверном вызове.
Для темы длительность сравнивается с `target`, когда тот указан; автоматический
хронометраж из текста в этой проверке пока не рассчитывается. Проверка не оценивает
художественное качество, читаемость текста, громкость и синхронизацию озвучки.
